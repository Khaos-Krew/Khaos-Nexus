# Khaos Nexus v0.26.7-B Startup Recovery

## Coordination

- Register revision: R8
- Decisions: ADR-001 through ADR-008
- Incident: #145
- Primary owner: Desktop Application Core
- Release owner: Release and CI
- Implementation branch: `recovery/v0.26.7-B-startup-rollback`
- Exact base: `v0.26.5-beta` / `6ba9ec550702b625b89060fe2ffe5d4ecbf60fdd`
- Owner validation: rolling back from `v0.26.6-B` to `v0.26.5-beta` restored normal startup.
- Stable fallback: `v0.26.0` / `6fbe660cf17b752e592ea8dd7f954a77ef5beb47`

## Corrective design

1. Rebuild draft preservation from the known-good beta baseline.
2. Do not add a new main-process startup extension or a new `main/entry.cjs` loader.
3. Load draft-protection renderer assets through the existing D&D usability extension.
4. Block destructive background rerenders only while editable D&D controls are dirty.
5. Queue newer state until a successful save or explicit discard.
6. Skip equivalent refresh renders to remove periodic flicker.
7. Preserve focus, selection, active campaign/tab, and scroll state.
8. Add focused regression tests plus a packaged Windows launch smoke test.
9. Publish updater-visible `v0.26.7-B` only after exact-head CI, Windows packaging, diagnostics, updater asset verification, and packaged startup smoke success.

## Scope boundaries

- Preserve all existing campaigns, credentials, settings, IPC contracts, Discord routing, diagnostics, updater, and game-adapter behavior.
- Do not include the unfinished visual UI refresh.
- Android Companion and Mobile Gateway remain paused and excluded under ADR-008.
