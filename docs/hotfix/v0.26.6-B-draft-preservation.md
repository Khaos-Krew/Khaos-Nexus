## Confirmed defect

The active D&D workspace polls every 15 seconds and replaces the complete workspace DOM after each `dnd:get` result. Incoming D&D state events also render immediately. These refresh paths discard unsaved values, selections, focus, editor state, and scroll position and retrigger enhancement observers, producing visible flicker.

## Repair contract

- Do not replace dirty or actively edited forms during background refresh.
- Cache live payloads until the draft is saved or explicitly discarded.
- Skip equivalent payload renders.
- Preserve tab, campaign, editor, focus, scroll, and draft state.
- Add regression coverage for polling and live-state events.
- Audit shared desktop configuration refresh behavior.
- Include the encounter-panel stability loader correction before publication.
- Keep unfinished UI refresh work excluded.
- Keep Android Companion and Mobile Gateway paused and excluded under ADR-008.
