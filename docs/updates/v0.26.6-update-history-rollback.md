## Authorized scope

Extend the existing Settings, update service, mandatory verified backup flow, updater IPC, diagnostics, and renderer systems with:

- a Settings → Updates surface;
- a bounded latest-10 compatible Windows release inventory;
- explicit Owner-only verified rollback;
- redacted rollback history;
- legacy release-label support;
- future public `-B` beta and `-R` stable labels while internal versions remain valid monotonic SemVer.

The always-visible header updater remains available. Existing configuration, credentials, campaigns, characters, modules, updater safety, and rollback baseline behavior must be preserved.
