## Implemented behavior

1. A remotely refreshable catalog of legally distributable free D&D content packs.
2. Trust is pinned to repository `Khaos-Krew/Khaos-Nexus`, ref `dnd-content-catalog`, path `catalog/dnd-free-content.json`, and approved repository actors. The catalog is fetched at the resolved immutable commit SHA.
3. Every downloadable file additionally requires an approved HTTPS host, exact declared size, supported type, file signature, and SHA-256 match.
4. Built-in offline fallback and last-known-good local catalog cache.
5. Explicit download, install, repair/update, open, license, and remove operations. No automatic content download or installation exists.
6. Protected local storage beneath the Khaos Nexus application-data directory with atomic writes and path-traversal rejection.
7. Installed packs create or update existing D&D source records. Removing a local file preserves campaign source selections.
8. Official SRD 5.2.1 and SRD 5.1 Creative Commons starter entries using hashes measured from the official downloads in CI.
9. A first-class Homebrew / Custom Source workflow with user-authored licensing, author, version, visibility, attribution, description, and external reference.
10. Character-sheet import using Khaos Nexus JSON and a documented generic JSON interchange shape.
11. Character import validates file type, size, JSON shape/depth, field ranges, Discord IDs, and provenance; unknown fields are retained only as inert metadata.
12. Import always reviews and creates a new character. It never accepts an imported record ID or silently overwrites a collision.

## Security and legal boundary

No paid rulebook content, marketplace material, D&D Beyond scraping, private API access, or automatic installation is included. Homebrew must be user-authored or otherwise permitted. Android Companion and Mobile Gateway remain excluded under ADR-008.
