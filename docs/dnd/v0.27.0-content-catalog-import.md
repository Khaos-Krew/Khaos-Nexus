## Scope

This production slice adds:

1. A signed, remotely refreshable catalog of legally distributable free D&D content packs.
2. Explicit download, SHA-256 verification, install, update, remove, and campaign-selection workflows.
3. Official SRD 5.2.1 and SRD 5.1 Creative Commons starter entries.
4. A first-class Homebrew / Custom Source workflow.
5. Character-sheet import using Khaos Nexus JSON and a documented generic JSON interchange format.

No content is downloaded or installed automatically. Paid or license-unclear material is not listed as installable full text. Android Companion and Mobile Gateway remain excluded under ADR-008.
