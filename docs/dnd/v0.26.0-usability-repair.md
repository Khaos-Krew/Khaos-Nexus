## Audit findings

### Preserved working implementation

- Campaign, member, character, session, attendance, source, Discord binding, grant, context, and panel IPC handlers already exist.
- Campaign and character normalizers already persist the required fields.
- The local-first encrypted registered-bot runtime and Supabase schema/security work remain intact.
- Existing Overview, Members, Sources, Discord, Sessions, and Party surfaces are retained.
- Campaign creation continues to create zero Discord resources.

### Confirmed defects

1. Campaign creation depended on native `prompt('Campaign name')`; the installed Owner build displayed no usable interaction.
2. Party displayed actual characters but provided no create, edit, selection, retirement, or update controls.
3. Form validation and IPC errors were not presented inside a durable D&D workflow.
4. Disabled or inaccessible module errors could leave only a loading or generic asset error state.
5. Existing tests verified source and loader wiring but did not execute campaign/character save flows.

## Implemented repair

- Intercepts the incomplete native campaign prompt and replaces it with an in-app modal.
- Campaign form includes name, ruleset, status, and description.
- Prevents duplicate submission and shows validation or IPC errors in the dialog.
- Selects and reloads the created campaign after a successful save.
- Adds a first-class Characters tab while preserving Party as read-only summary.
- Supports character create, edit, set-active, and retire operations through `dnd:character-save`.
- Supports owner and Discord association, level, class, HP, maximum HP, Armor Class, conditions, inspiration, exhaustion, status, initiative modifier, portrait URL, active quest, and selection state.
- Maintains one selected character per linked Owner/Discord identity when an association is present.
- Presents a clear, non-destructive unavailable state when D&D is disabled or Owner authorization is missing.
- Loads the repair assets independently so the usability surface can report its own loader failure.
- Adds focused executable tests for campaign and character interaction flows.
