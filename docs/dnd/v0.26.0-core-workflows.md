## Verified production gaps

The foundation stores or consumes sources, quests, encounters, combatants, and attendance, but the desktop does not provide complete Owner creation and editing workflows for them. Initiative therefore cannot be configured end-to-end through the installed application, and source/quest/attendance records require incomplete or external paths.

## Target

Add visible, authorized, audited workflows for:

- source metadata and campaign source enablement;
- quest creation/editing and active quest selection;
- encounter lifecycle and combatant setup;
- deterministic initiative setup without rotating stored order;
- session attendance for campaign members.

Preserve all existing data, registered-bot routing, Supabase controls, Discord resource-creation restrictions, session protections, and Party/campaign behavior.
