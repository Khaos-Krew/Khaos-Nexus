## Scope

This production slice adds protected local map assets, deterministic local generation, pan/zoom, square and hex grids, persistent linked markers, party position, visibility controls, and snapshot export while preserving existing locations, NPCs, characters, quests, encounters, and loot.

It is a desktop campaign-map foundation, not a hosted browser VTT. Android Companion and Mobile Gateway remain excluded under ADR-008.
