# Khaos Nexus v0.18.15

## Main interface reliability

- The protected renderer bridge is now marked ready only after the real `renderer/index.html` document contains the application shell, sidebar, content pane, and an active workspace.
- The initial Electron `about:blank` document can no longer satisfy startup readiness.
- A main-process watchdog independently checks the interface after load and at the startup deadline.
- Main-frame load failures, renderer-process exits, inspection failures, and blank or hidden interfaces are retained locally and queued for Application Monitor reporting.
- A visible local recovery screen replaces the empty black window and includes the retained error ID and diagnostic path.
- Portable runs mirror the watchdog report into `Khaos-Nexus-Portable-Data`.

## Preserved behavior

- The always-visible **Check for Updates** control remains under System → Settings.
- Updates still use Check → Download → Install & Restart.
- A mandatory verified pre-update backup is still required before installation.
- The owner-verified startup, scrolling, grouped navigation, server controls, Discord runtime, and portable diagnostics remain in place.
