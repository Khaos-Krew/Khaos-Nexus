# Khaos Nexus v0.27.0-beta.1 — D&D Feature Test

This is an Owner testing prerelease. It does not replace stable v0.26.0 and is not offered through the v0.26.0 Update Center because that stable updater intentionally rejects prereleases.

## Included D&D test features

- Free-content catalog with official SRD metadata, protected downloads, Homebrew/custom sources, and reviewed character JSON import.
- Protected local campaign maps with uploads, deterministic local generation, pan/zoom, square or hex grids, linked markers, party position, visibility controls, and PNG snapshot export.
- Full NPC builder with narrative and combat modes, deterministic local generation, relationships, portraits/tokens, JSON import/export, reveal controls, campaign links, and encounter insertion.
- Persistent Discord encounter panels with featured-boss health modes, player-safe initiative and party state, configured current-turn roll buttons, DM override controls, stale-button rejection, private-roll routing, and explicit DM-controlled HP/condition changes.

## Preserved boundaries

- Stable rollback remains `v0.26.0` at `6fbe660cf17b752e592ea8dd7f954a77ef5beb47`.
- No unfinished shared UI refresh from issue #131 / PR #132 is included.
- Android Companion and Mobile Gateway remain paused and excluded under ADR-008.
- No Discord categories or campaign channel structures are created automatically.
- No automatic damage or healing is applied; the DM remains authoritative.

## Suggested Owner validation

1. Install over v0.26.0 and confirm existing configuration, campaigns, characters, credentials, and module state remain present.
2. Test catalog refresh/install/remove, Homebrew source creation, and character import review.
3. Create or upload a map, add and move linked markers, change visibility, and export a PNG snapshot.
4. Create, generate, import, edit, duplicate, archive, reveal, and link NPCs; add a combat NPC to an encounter.
5. Configure and publish an encounter panel to an existing bound Discord resource.
6. Advance initiative, adjust HP/conditions manually, test public and private roll buttons, verify stale buttons reject, and confirm hidden combatants/GM notes never appear publicly.
7. Confirm the application reports version `0.27.0-beta.1`.

Report findings on the owning D&D GitHub issues. UI refresh production continues separately after this feature test.
