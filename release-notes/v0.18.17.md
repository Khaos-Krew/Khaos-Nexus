# Khaos Nexus v0.18.17

## Renderer unfreeze correction

- Removed the updater UI's permanent whole-document MutationObserver.
- The prior observer called `render()` after every child-list mutation, while `render()` changed updater button text and could immediately trigger the observer again.
- Updater rendering is now idempotent and only changes text or disabled state when the value actually differs.
- Three bounded reconciliation checks replace continuous DOM observation.
- The updater remains visible under Settings and retains Check, Download, and Install & Restart behavior.

## Failure reporting

- Main-process monitoring now listens for Electron renderer `unresponsive` events.
- An unresponsive desktop creates the same retained watchdog report, crash diagnostic, Application Monitor queue entry, and recovery path as a failed or blank renderer.

The v0.18.16 visible-interface gate, original navigation safe mode, scrolling corrections, portable diagnostics, and mandatory verified pre-update backup remain enabled.
