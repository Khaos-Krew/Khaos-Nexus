# Khaos Nexus v0.41.1-B — Acceptance Hotfix

This Test/Beta build is the acceptance hotfix for the v0.41 Nexus Core migration. It is intentionally published on the opt-in Test/Beta update channel; v0.41.0-B remains the Stable/latest rollback point until this build completes live acceptance.

## AI runtime recovery

- Isolates Sentinel and Veyra bundle health so one unavailable worker no longer blocks the other.
- Improves per-worker lifecycle status and start/restart controls.
- Adds the local conversational provider path for Nexus Sentinel while preserving deterministic Nexus Core authority and capability boundaries.
- Keeps provider execution local/loopback-only and separate from privileged tools.

## Palworld / Nitrado acceptance path

- Makes the Palworld REST API the required authoritative connection.
- Adds optional RCON compatibility/testing controls without making deprecated RCON a production dependency.
- Migrates legacy RCON-only entries to REST-primary configuration while preserving the old endpoint for optional verification.
- Adds guarded RCON Info, Players, Save, Broadcast, and custom-command testing with capability and confirmation gates.
- Keeps update detection, Discord/in-game maintenance warnings, save-before-shutdown, idempotency, and interrupted-operation recovery behind Nexus Core.
- Does not require Nitrado developer API credentials for the normal Palworld path.

## Desktop acceptance fixes

- Improves responsive behavior for narrow, portrait, and multi-monitor window layouts.
- Preserves the single renderer state authority and Nexus Core mutation gateway.
- Keeps mandatory verified pre-update backup and rollback protections.

## Acceptance note

Automatic Palworld maintenance restart remains disabled until the target Nitrado server's post-shutdown relaunch behavior is verified live. Failed or interrupted destructive maintenance steps fail closed and are not replayed automatically.
