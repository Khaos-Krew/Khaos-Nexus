# Khaos Nexus v0.22.0

## Native Android Companion — Phase 1

- Added a native Kotlin and Jetpack Compose Android application.
- Added a read-only Command Deck for desktop, Discord, game-server, module, log, status-panel, and update visibility.
- Added QR scanning through Google Code Scanner without requiring a permanent camera permission.
- Added deep-link pairing support through `khaosnexus://pair`.
- Blocked Android screenshots and screen recording.
- Disabled Android backup and cleartext HTTP.

## Desktop HTTPS Mobile Gateway

- Replaced the dormant mobile foundation with an implemented Owner-controlled HTTPS gateway.
- Added a per-installation TLS certificate and visible SHA-256 fingerprint.
- Added trusted local-network and private-network/VPN modes; public router port forwarding is not supported or recommended.
- Added five-minute QR and six-digit pairing sessions.
- Added explicit desktop Owner approval showing the Android device name, requested role, and public-key fingerprint.
- Added one-time device credential delivery.
- Added immediate device revocation and live stream closure.
- Added certificate rotation that revokes all paired devices.

## Request and Credential Security

- Android creates a non-exportable P-256 signing key in Android Keystore.
- Android encrypts its device credential with Android Keystore-backed AES-GCM storage.
- The desktop stores only a scrypt hash and salt for each device credential.
- Every authenticated request signs the exact method, path and query, timestamp, nonce, and body digest.
- Added a two-minute timestamp window and five-minute nonce replay protection.
- Added request-body limits, header timeouts, per-device limits, and pre-authentication rate limits.
- Pairing state and device administration are Owner-only on the desktop.
- Protected desktop credentials are redacted before any response leaves the desktop.

## Reliability and Owner Control

- The Mobile Gateway remains disabled until both its Owner module and gateway setting are enabled.
- Module disable, Disable All, and bulk module changes reconcile the HTTPS listener immediately.
- Device last-seen persistence is throttled to avoid high-frequency configuration writes.
- Added real TLS lifecycle regression coverage: certificate generation, HTTPS health, QR creation, redaction, shutdown, socket cleanup, and timer cleanup.
- The existing v0.21.0 Rust WebRCON, Game Adapter SDK, module control, startup, updater, monitor, scheduler, player moderation, and Windows packaging foundations remain protected by the full regression suite.

## Android Build Gates

- Android SDK 36, Java 17, Gradle 9.5, AGP 9.3, Kotlin Compose plugin 2.3.21, and the current Compose BOM are pinned in source.
- The Owner-test workflow runs unit tests, lint, APK assembly, APK signature verification, checksum generation, and artifact upload.
- Owner-test APKs use the Android debug signing identity and are for private validation only.
- Stable Android release builds require the permanent external keystore through repository secrets and cannot silently fall back to debug signing.

No stable desktop or Android release is automatically published from the Owner-test candidate.
