# Khaos Nexus v0.18.16

## Visible interface startup gate

- Startup can no longer release only because IPC and configuration services are available.
- The real desktop shell must remain structurally usable for three continuous seconds before the splash may close.
- Main-window discovery retries until it finds the actual desktop BrowserWindow rather than relying on one creation-time preload check.
- The watchdog continues inspecting after startup and detects a window that becomes blank after initially rendering.
- A near-uniform dark capture is treated as an effectively blank rendered surface.

## Diagnostics

- `interface-watchdog-state.json` is created for healthy and failed runs.
- `logs/interface-watchdog.log` is written in the normal AppData profile for installed and portable builds.
- Startup release diagnostics include the attached window, interface stage, stability state, DOM snapshot, and visual capture metrics.
- Failures still create a recovery screen, retained diagnostic report, crash report, and Application Monitor queue entry.

The updater button, verified pre-update backup, grouped navigation, independent scrolling, server management, Discord automation, and website migration work remain unchanged.
