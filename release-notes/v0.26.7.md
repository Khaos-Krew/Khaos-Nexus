# Khaos Nexus v0.26.7-B

This recovery beta restores normal startup while retaining the D&D draft-preservation fix.

## Fixed

- Rebuilds draft preservation from the known-good `v0.26.5-beta` startup baseline.
- Removes the separate main-process draft-preservation startup extension introduced in `v0.26.6-B`.
- Loads draft-protection CSS and renderer logic through the existing D&D usability extension.
- Prevents the 15-second D&D refresh and live state events from replacing actively edited controls.
- Queues newer campaign data until Save succeeds or the Owner explicitly discards the draft.
- Skips equivalent workspace renders to reduce periodic flicker.
- Preserves unsaved values, checkboxes, dropdowns, focus, text selection, active campaign/tab, and scroll position.
- Keeps failed saves from releasing protected edits.

## Release safety

- Adds a packaged Windows startup smoke test after building the unpacked application.
- The packaged process must remain alive through the startup window and expose an Electron window before artifacts can pass.
- Existing campaigns, credentials, settings, and verified pre-update backups are preserved.
- Immediate rollback remains `v0.26.5-beta`.
- Stable fallback remains `v0.26.0`.
- Android Companion and Mobile Gateway remain paused and excluded under ADR-008.
- The unfinished visual UI refresh is not included.
