# Khaos Nexus v0.18.14

## In-app updater button restored

- Fixes the missing **Check for Updates** button in v0.18.11 through v0.18.13.
- Inserts the primary updater button into the existing Desktop Settings action row when the optional Update Center panel is not present.
- Leaves the original legacy update button visible unless the replacement button was successfully created.
- Creates a small fallback Update Center only when neither normal settings action area is available.

## Update flow

- **Check for Updates** checks the stable GitHub release channel.
- **Download vX.Y.Z** downloads and verifies the update.
- **Install & Restart** creates and verifies the mandatory pre-update backup before installation.

## Preserved behavior

- Owner-verified startup and 30-second health screen.
- Independent navigation and workspace scrolling.
- Searchable collapsible navigation groups.
- Portable sidecar diagnostics.
- Existing local configuration, servers, and protected values.
