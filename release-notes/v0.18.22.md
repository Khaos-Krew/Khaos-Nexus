# Khaos Nexus v0.18.22

## Full production runtime audit and repair

This guarded candidate audits and repairs the production paths inherited through v0.18.21 without replacing the working startup, navigation, Discord supervision, protected configuration, or backup foundations.

### Discord runtime and status panels

- Starts the supervised Discord process through an audited wrapper while retaining the existing bot implementation.
- Applies live `config-update` messages to the active bot configuration instead of requiring a bot restart before saved servers and status panels are visible.
- Implements the existing **Refresh Status** and **Show Players** status-panel buttons.
- Keeps button responses public-safe, ephemeral, mention-free, and rate-limited.
- Preserves the valid `🔄` component emoji fix for Palworld status panels.
- Converts utility-process spawn failures into a visible Error state instead of leaving Discord stuck on Starting.

### Application Monitor

- Makes the manual Process Queue path truly immediate instead of being blocked by the next scheduled batch time.
- Enforces the configured daily GitHub delivery limit for automatic batches.
- Starts the thirty-minute recurring maintenance scan even when the five-minute startup batch encounters an error.
- Retains failed deliveries for retry rather than dropping reports.

### Server safety and recovery

- Removes stale health entries for servers that were deleted or disabled, preventing permanent false Attention states.
- Detects scheduler workflows interrupted by an application restart and closes them safely without replaying shutdown or restart commands.
- Avoids rewriting scheduler runtime state every fifteen seconds when nothing was pruned.
- Rejects `host:port` values in RCON host fields and directs the user to the separate port field.
- Validates RCON host and port values before opening a network connection.
- Distinguishes unresolved hosts, refused ports, authentication failures, pre-auth disconnects, and post-auth response failures with actionable guidance.

### Updating and lifecycle

- Returns a failed portable installation launch to a retryable Downloaded state instead of leaving the updater stuck on Installing.
- Validates the staged portable executable and original target before changing the update state.
- Disposes update timers during application shutdown.

### Preserved foundations

- v0.18.21 grouped navigation click routing.
- Always-visible header updater and dedicated Update Center.
- Mandatory verified pre-update backup.
- v0.18.18 Discord online/PID synchronization.
- v0.18.17 renderer-unfreeze and visible-interface startup validation.
- Protected credential storage, backups, portable diagnostics, access recovery, Pterodactyl controls, player moderation, scheduler warnings, and automatic error capture.

Stable publication remains blocked until the complete CI suite, syntax audit, Windows installer/portable packaging, and owner-device validation are complete.
