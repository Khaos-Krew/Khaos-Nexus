# Khaos Nexus v0.22.1

## Local Module Recovery Hotfix

This maintenance release removes the Discord-derived Owner lock from the desktop Module Center. Local module recovery controls never depend on Discord ownership.

### Fixed

- The person running the local desktop application can always enable and disable modules.
- Disable All, Safe Mode, and Enable Validated remain available even when Discord is offline, signed out, misconfigured, or reporting the wrong role.
- Module migration notes and checklist controls remain accessible from the local installation.
- Discord, mobile, game-server, and remote-operation permission checks remain unchanged.
- The local authority layer installs before module IPC handlers register, preventing the lockout from returning during startup.

### Preserved

- Native Android Companion Phase 1 and the certificate-pinned HTTPS Mobile Gateway.
- Rust WebRCON, Palworld REST, ARK/generic RCON, status panels, scheduler, updater, monitoring, backups, and startup recovery.
- Protected pre-update backup and in-app update installation flow.
