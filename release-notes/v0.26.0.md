# Khaos Nexus v0.26.0

Khaos Nexus v0.26.0 delivers the complete first production-ready Dungeons & Dragons desktop module while preserving the validated v0.25.0 desktop, updater, diagnostics, Discord, server-management, and security behavior.

## Complete D&D campaign management

- Create, reopen, edit, and manage campaigns through visible in-app controls.
- Create, edit, select, retire, and review characters with level, class, health, armor class, conditions, inspiration, exhaustion, initiative, portrait, quest, and Discord associations.
- Manage campaign members and per-campaign source settings.
- Create source metadata with provenance, attribution, license classification, and guarded full-text controls.
- Create and manage quests, player-visible summaries, GM notes, lifecycle states, and the campaign's active quest.
- Plan sessions, start and end sessions safely, record attendance, and preserve recap approval safeguards.
- Create encounters, add character or manual combatants, manage encounter lifecycle, and advance deterministic initiative without destructive resets.
- Manage NPCs, locations, factions, reveal controls, shared or assigned loot, content metadata, and campaign world records.
- Create, submit, review, approve, reject, revise, and retire homebrew with immutable approved revisions.
- Roll dice locally with a strict parser, cryptographic randomness, persisted history, privacy, modifiers, kept dice, totals, and character/session associations.
- Bind campaigns to existing Discord channels, threads, or forum posts through registered bots without automatically creating categories or campaign channel collections.

## Reliability and data safety

- Replaces the nonfunctional native campaign prompt with an in-app workflow that displays validation and IPC errors.
- Adds explicit disabled-module and Owner-access states instead of repeated loading errors.
- Preserves existing campaign data, Supabase security controls, registered-bot routing, encrypted credentials, updater backups, diagnostics, game adapters, schedules, and local configuration.
- Includes validated installer and portable Windows builds, electron-updater metadata, blockmap, and SHA-256 checksums.

## Legal and content boundaries

- No paid rulebook text is seeded or reproduced.
- Full content is accepted only when its recorded origin and license explicitly permit storage.
- D&D Beyond remains link-only or limited to permitted user-controlled imports unless an authorized API or export path exists.

## Android production hold

Android Companion and Mobile Gateway are paused and excluded by Owner directive under ADR-008. No APK or Android setup link is included in this release. Existing Android and Mobile Gateway source and security evidence remain preserved for a future explicitly authorized resumption.

## Upgrade notes

The Update Center will create and verify a protected pre-update backup before installation. Existing desktop configuration, encrypted credentials, modules, server definitions, schedules, campaigns, and D&D records are preserved during the upgrade from v0.25.0.
