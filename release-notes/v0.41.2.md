# Khaos Nexus v0.41.2-B — Nexus Core v1 Validation Update

This build advances the Nexus Core v1 candidate beyond the already-published v0.41.0-B and v0.41.1-B releases and is intended for the next owner test cycle.

## Nexus Core

- Preserves the single local Nexus Core composition root for authorization, command execution, idempotency, operational events, recovery, context isolation, worker supervision, and AI tool boundaries.
- Keeps shared-scheduler save, announcement, shutdown, moderation, hosted-server power, and supported game-server mutations routed through capability-gated Core execution.
- Retains append-only operational journaling, checksummed projections, and conservative interrupted-operation recovery.

## Desktop and updater

- Uses the current Core/renderer state-hub architecture and the previously merged heartbeat/navigation refresh fix.
- Publishes as v0.41.2-B so the updater moves forward from the current v0.41.1-B release instead of attempting a downgrade or colliding with an existing tag.
- Uses v0.41.1-B as the rollback target.
- Keeps verified pre-update backups, artifact verification, clean-install smoke, packaged-startup smoke, and updater metadata validation in the release gate.

## Active product scope

- D&D remains part of the active Khaos Nexus product surface and continues to use the current campaign-management and AI boundaries.
- Android Companion and Mobile Gateway remain paused and excluded from this Windows release.
- No APK or Android setup link is included in this build.

## AI and security

- Preserves Veyra and Nexus Sentinel context isolation and deterministic Core authority boundaries.
- AI services remain without unrestricted RCON, shell, SQL/database, Discord-token, or secret authority.
- Secret and credential redaction protections remain enforced.

This is a validation/test build. Owner testing should focus only on changed or newly exposed behavior; previously validated stable paths do not need to be re-proven without a practical test target.
