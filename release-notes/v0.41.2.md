# Khaos Nexus v0.41.2-B — Stability Baseline

This build restores the desktop product line to the v0.41.x sequence and starts the Nexus Stabilization Reset.

## Stability focus
- preserve the approved modern Nexus shell and navigation
- block legacy loading-screen, sidebar, and navigation regressions
- require the 12-gate functional stability score before owner testing
- keep feature expansion frozen until the desktop baseline is dependable

## Release identity
- current candidate: v0.41.2-B
- previous known-good rollback target: v0.41.1-B
- Sentinel 0.33.0 RC1 is not part of the main desktop version line and is not an accepted baseline
- D&D remains part of the Khaos Nexus Windows desktop product scope during stabilization; it is not a separate successor product or release line.
- Android Companion and Mobile Gateway remain paused and excluded from the current Windows stabilization/release scope.

This is a validation build. It must not be promoted until the stabilization gates pass.
