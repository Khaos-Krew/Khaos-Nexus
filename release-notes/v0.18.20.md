# Khaos Nexus v0.18.20

## Grouped navigation and visible in-app updates

- Replaces the long flat sidebar list with searchable, collapsible groups for Servers, Discord & Community, Automation, Modules & Tools, and System.
- Keeps every working original navigation button in its original DOM location and uses safe proxy buttons, avoiding the startup-time reparenting that previously caused blank or frozen interfaces.
- Adds bounded reconciliation so workspaces injected during startup appear in the correct group without a permanent MutationObserver.
- Adds an always-visible update button beside the application status in the header.
- Adds a dedicated Update Center under Settings in software compatibility mode and reuses the rich Update Center when available.
- Preserves Check, Download, and Install & Restart as explicit steps with a mandatory verified pre-update backup.
- Retains the v0.18.19 compact dashboard pass, v0.18.18 Discord runtime state and supervised PID synchronization, and v0.18.17 renderer-unfreeze behavior.
- Retains automatic error capture, the five-minute startup error batch, thirty-minute maintenance scans, protected credentials, local configuration, portable diagnostics, and visible-interface startup validation.

This build is a guarded Windows production candidate. Stable publication remains blocked until the grouped navigation, visible updater, startup, Discord runtime, and error monitor are verified on the owner PC.
