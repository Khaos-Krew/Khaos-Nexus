# Khaos Nexus v0.28.0-B — Khaos Nexus AI Co-DM Integration

This unpublished beta candidate builds on `v0.27.1-B`. It completes the desktop-side D&D Co-DM workspace and connects it to the separate `Khaos-Krew/Khaos-Nexus-AI` runtime without placing AI provider credentials or provider implementation inside the Khaos Nexus desktop application.

## Separate Khaos Nexus AI runtime

- AI providers, provider credentials, model routing, prompt policy, campaign-AI memory, safety logic, and provider-specific retries remain owned by the separate Khaos Nexus AI service.
- The desktop stores no OpenAI API key and contains no direct OpenAI request path for the D&D Co-DM workflow.
- The default local endpoint is `http://127.0.0.1:8787`.
- Plain HTTP is accepted only for loopback hosts; remote service endpoints require HTTPS.
- Service URLs containing embedded credentials, query parameters, or fragments are rejected.
- An optional Khaos Nexus AI service token can be stored using the existing protected desktop secrets store.
- The service token is excluded from backups, diagnostics, public configuration, Discord bot bootstrap data, renderer state, and application logs.

## Capability negotiation and compatibility

- The desktop checks `GET /health` for service status, provider, model, version, and advertised capabilities.
- A future `dnd.co-dm.draft` capability is preferred automatically through `POST /api/v1/dnd/co-dm/drafts`.
- The validated current AI MVP is supported through:
  - `POST /api/v1/campaigns`;
  - `POST /api/v1/campaigns/:id/turns`.
- Compatibility mode creates a bounded redacted campaign copy in the AI service and reuses it until the selected context fingerprint changes.
- Because the current MVP stores its campaign state and turn transcript, every compatibility-mode generation requires a visible Owner confirmation.
- The exact validated AI MVP snapshot is pinned in the cross-repository integration workflow so later AI changes do not silently change this desktop candidate.

## Private Co-DM workspace

- Adds an Owner/local-admin-only **Co-DM** tab to the existing D&D workspace.
- Displays Khaos Nexus AI connection, provider, model, service version, and operating mode.
- Includes a connection test and clear compatibility-mode persistence disclosure.
- Adds campaign readiness checks for:
  - selected campaign;
  - AI service availability and generation capability;
  - AI provider/model report;
  - campaign members and characters;
  - enabled sources;
  - registered D&D bot;
  - Discord binding and persistent campaign panel;
  - upcoming session.

## Redacted campaign context

- Every generation is explicitly initiated by the Owner.
- The desktop constructs and previews the exact bounded campaign context before it is sent.
- Context controls independently cover:
  - character details;
  - encounter details;
  - recent session recaps;
  - GM notes and secrets;
  - approved homebrew text;
  - recent public rolls.
- GM notes, campaign Co-DM notes, and approved homebrew bodies require explicit opt-in.
- Character records are omitted from both the context text and the compatibility campaign request when character details are disabled.
- Blind rolls, DM-only rolls, Discord IDs, grants, channel bindings, application IDs, audit records, protected files, credentials, and unprovided licensed full text are excluded.
- Context uses deterministic character limits, section counts, inclusion reasons, truncation indicators, and stable fingerprints.
- Campaign text is marked as untrusted reference data and is never treated as system instructions.

## Co-DM draft workflows

The desktop can request reviewable drafts for:

1. session preparation;
2. session recap;
3. encounter ideas and balance review;
4. NPC dialogue and roleplay guidance;
5. quest, faction, and world hooks;
6. selected-source rules research.

The current structured campaign-turn compatibility response is rendered into local review sections for narration, dialogue, suggested checks, table options, proposed campaign updates, and safety status.

## Local review and approval boundary

- Generated results are stored as bounded local drafts.
- Draft history supports copy, rename, pin/unpin, and delete.
- Drafts record the workflow, AI service/provider/model/version, context summary, and generation mode.
- Prompts, service tokens, private generated content, and private context are not written into audit metadata.
- Copying a draft into a session recap or campaign Co-DM notes requires explicit confirmation.
- Generation never automatically:
  - changes campaign records;
  - applies proposed world facts, open threads, or notes;
  - changes HP, initiative, encounters, quests, NPCs, loot, or homebrew;
  - rolls dice;
  - posts to Discord;
  - creates Discord resources;
  - invokes game-server actions.

## Persistence and privacy repairs

- Co-DM settings, local drafts, private campaign Co-DM notes, and AI campaign bindings survive the existing D&D normalization layer.
- Draft timestamps remain stable during reads and normalization and change only after explicit edits or saves.
- Private Co-DM state is removed from generic public configuration, diagnostics exports, and Discord bot runtime synchronization.
- AI campaign service bindings remain local and are not exposed to the Discord runtime.
- Legacy desktop OpenAI-key state is removed from the active Co-DM path and is excluded from backups.

## Stability and accessibility

- The Co-DM UI uses a bounded D&D-root observer only.
- No whole-document mutation observer or permanent fast polling loop is introduced.
- Tab recovery avoids recursive rerender loops.
- Layout supports responsive widths and reduced-motion preferences.
- Existing hidden-view deferral, frame-batched visible updates, startup recovery, and packaged-startup safety remain intact.

## Preserved D&D module behavior

The complete existing D&D feature set remains included:

- campaigns and campaign members;
- characters and dice history;
- licensed source metadata and per-campaign source controls;
- content catalog, imports, and existing homebrew draft/approval workflow;
- quests, sessions, attendance, locations, factions, loot, and world records;
- protected campaign maps;
- NPC builder;
- encounters, combatants, initiative, and turn controls;
- registered Discord bots, grants, channel/thread/forum bindings;
- persistent campaign and encounter panels;
- previewed, confirmed, idempotent Discord campaign-space provisioning;
- no Discord role creation by default.

## Preserved diagnostics and desktop behavior

- The automatic startup health integration from `v0.27.1-B` remains included.
- Standalone `--diagnostics`, cached verified runtime fallback, local support bundles, startup watchdogs, recovery mode, and packaged-startup readiness remain intact.
- Application Monitor remains disabled by default and GitHub delivery continues to require explicit consent.
- Android Companion and Mobile Gateway remain paused and excluded under ADR-008.

## Validation completed before version freeze

The unversioned implementation passed:

- dependency audit, complete tests, and repository checks;
- Windows installer and portable packaging;
- packaged full-start readiness;
- artifact verification;
- a live cross-repository integration workflow that checked out the validated Khaos Nexus AI MVP, started its deterministic mock service, verified health, created a campaign through the real API, generated a structured turn, and converted it into a desktop Co-DM draft.

The version-frozen source must pass those same gates again before it is considered prepared.

## External dependency and publication state

- The Khaos Nexus AI service is not bundled into this Windows candidate.
- A usable Co-DM generation session requires a compatible Khaos Nexus AI service running at the configured endpoint.
- The public updater release remains unchanged.
- No public tag, GitHub release, publisher pull request, or in-app updater entry is authorized for `v0.28.0-B`.
- Publication remains blocked until the Owner explicitly commands it.

## Rollback

If this candidate is later published, its immediate rollback target is `v0.27.1-B`.
