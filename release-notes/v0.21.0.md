# Khaos Nexus v0.21.0

## Rust WebRCON Operations

- Added a dedicated Rust server type using WebRCON instead of pretending Rust uses legacy Source RCON.
- Added encrypted Rust WebRCON password storage with separate host, port, `ws`/`wss`, and RCON client-name settings.
- Added typed vanilla-safe operations for server information, JSON player lists, announcements, world saves, kicks, bans, unbans, graceful shutdown, immediate stop, and Owner raw console access.
- Graceful Rust shutdown saves the world first and treats the expected WebSocket disconnect caused by `quit` as successful completion.
- Added a dedicated Rust operations workspace inside Game Servers.

## Owner Module Control

- Added **Rust Server Operations** as an implemented Owner-controlled module.
- Disabling the module immediately blocks desktop Rust actions, Discord Rust commands, status-panel refreshes, player moderation, autonomous health checks, maintenance actions, and schedules targeting Rust.
- The Game Servers editor remains available while the module is disabled so broken Rust settings can be repaired before re-enabling it.

## Discord Integration

- Added Rust to `/status`, `/players`, `/saveworld`, `/broadcast`, `/kick`, `/ban`, `/unban`, `/shutdown`, `/forcestop`, `/rcon`, and `/listservers` where the adapter declares support.
- Discord server choices are filtered by actual adapter capabilities.
- Discord game operations now use the shared Game Adapter SDK rather than calling transports directly.
- Raw console commands are restricted to the configured Khaos Nexus Owner account.
- Rust status panels can display players, queue, joining count, map, entity count, server FPS, uptime, and optional player names.

## Security and Reliability

- WebRCON requests use identifier matching and ignore unrelated console packets.
- Added request timeout, cancellation, malformed-response handling, response-size limits, and expected-shutdown disconnect handling.
- WebRCON passwords are removed from raw, percent-encoded, and URL-embedded error messages.
- Typed Rust arguments reject line breaks and semicolon command chaining.
- Rust moderation requires Steam64 identifiers.
- Standard `ws` WebRCON is clearly labeled as unencrypted; `wss` is available for a trusted TLS reverse proxy without disabling certificate validation.
- Common audit repairs are installed before Rust extends health, maintenance, and scheduler services, then Owner module gates are reapplied to the final overrides.

## Preserved v0.20.0 Foundations

- Typed Game Adapter SDK and capability manifests.
- Owner module switches, Disable All, Safe Mode, and Enable Validated.
- Palworld REST, ARK RCON, generic RCON, Pterodactyl, player moderation, schedules, status panels, embeds, monitoring, backups, updater, startup recovery, and supervised Discord runtime behavior.

No stable release is automatically published from the Owner-test candidate.
