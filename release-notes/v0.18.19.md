# Khaos Nexus v0.18.19

- Compacts the Command Center so more runtime information fits in the first viewport without removing controls or data.
- Reduces sidebar, branding, navigation, header, task-card, hero, metric, panel, activity, and quick-launch spacing.
- Prevents long navigation and task labels from wrapping into uneven rows while retaining full workspace access.
- Makes the runtime task rail responsive across narrower desktop windows.
- Refines disabled-action styling, pane scrollbars, responsive layout behavior, and reduced-motion support.

## Discord runtime state synchronization retained

- Keeps the v0.18.18 Discord runtime state synchronization that prevents an older startup snapshot from replacing a newer live runtime update.
- Keeps a connected supervised Discord runtime presented as online and healthy.
- Keeps the spawn-confirmed Electron utility-process PID visible to the Command Center.

## Safety retained

- Preserves all v0.18.17 startup and renderer-unfreeze behavior.
- Does not alter startup gating, renderer coordination, Discord supervision, protected credentials, local configuration, updater behavior, mandatory verified pre-update backups, portable diagnostics, or the original-DOM navigation safe mode.
- The production cleanup is limited to the dashboard presentation layer plus matching release metadata and regression coverage.
