# Khaos Nexus v0.33.0-B

## Test candidate

This beta candidate bundles Khaos Nexus D&D AI and Nexus AI Core with the Windows desktop application so a separate Node.js installation is not required.

### Added

- Verified read-only D&D AI `0.12.1` runtime bundle from `19c718917377d6148f9baaee8ac8dcb937692f32`.
- Verified read-only Nexus AI Core `0.7.0` runtime bundle from `300c653e5643e0ee2e15590f8cb53e30ee7a79ff`.
- Electron embedded-Node launch using `ELECTRON_RUN_AS_NODE=1`.
- Automatic local startup and clean shutdown for both isolated services.
- Separate process, endpoint, data directory, logs, lifecycle state, and failure handling for each service.
- Bundle manifests with repository, commit, version, entry point, file size, and SHA-256 integrity records.

### First-run test mode

- D&D AI starts locally with the mock provider, JSON campaign storage, and authentication disabled for connection testing.
- Nexus AI Core starts locally with its deterministic provider.
- No OpenAI key, Supabase secret, provider token, or campaign credential is embedded in the installer.

### Preserved boundaries

- D&D AI and Nexus AI Core remain isolated and never call one another.
- Khaos Nexus desktop, Nexus Bot, the shared scheduler, and game adapters remain authoritative.
- AI service failure does not disable normal desktop, Discord, scheduler, updater, D&D, or game-server controls.
- Android Companion and Mobile Gateway remain paused and excluded from production under ADR-008.
- No APK or Android setup link is included.

### Test focus

- Update from `v0.32.0-B` to `v0.33.0-B` on a Windows machine with no global Node.js installation.
- Confirm both service processes start using the packaged Khaos Nexus executable.
- Confirm D&D AI health at `127.0.0.1:8787` and Nexus AI Core health at `127.0.0.1:8790`.
- Confirm one service can stop or fail without affecting the other.
- Confirm bundle tampering prevents launch.
- Confirm uninstall, updater rollback, and portable execution do not leave service processes running.

This candidate is intended for controlled Owner testing before broader publication.
