# Khaos Nexus v0.26.8-B — Owner-Device Startup Rollback

This emergency updater release restores the exact application behavior from the Owner-verified `v0.26.5-beta` baseline after `v0.26.6-B` and `v0.26.7-B` failed startup validation.

## Restored

- Known-good desktop startup and full module initialization from `v0.26.5-beta`.
- Existing application data, protected credentials, settings, D&D records, server configuration, and backups remain in place.
- The draft-preservation changes from the two failed releases are intentionally excluded.

## Release safety

- The packaged Windows gate now requires the startup health controller to report phase `ready`.
- Limited Mode, `needs-attention`, startup failure, missing renderer readiness, or a visible window without full readiness fails publication.
- Android Companion and Mobile Gateway remain paused and excluded under ADR-008.

## Rollback

The immediate manual rollback remains `v0.26.5-beta`. Stable fallback remains `v0.26.0`.
