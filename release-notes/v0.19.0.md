# Khaos Nexus v0.19.0

## Owner-controlled module runtime

This guarded candidate completes the desktop module migration framework and gives the Owner authoritative control over which implemented systems may run.

### Owner controls

- Enable or disable individual implemented modules from the Modules workspace.
- **Disable All** hides and blocks optional operational modules while retaining access to the module center.
- **Safe Mode** keeps diagnostics and backup/update foundations available while Discord, game-server and optional automation systems remain disabled.
- **Enable Validated** restores every fully implemented module without enabling planned concepts that do not yet have runnable code.
- Owner choices are stored separately from migration progress, so later extension migrations cannot silently re-enable a module that was intentionally disabled.
- Dependencies use a visible **Blocked** state. Re-enabling the dependency restores requested child modules without losing their saved choices.

### Runtime enforcement

Disabled modules are now enforced across:

- grouped sidebar navigation and module workspaces;
- protected main-process IPC operations;
- Discord supervised-process start;
- update checks, downloads and installs;
- automatic backups, health checks, recovery and maintenance;
- Application Monitor delivery;
- server schedules and restart workflows;
- status-panel publication and automatic refresh;
- Discord Observability delivery;
- Discord slash-command registration and execution;
- game-specific server command filtering;
- existing Discord status-panel buttons;
- existing role-menu and color-role buttons.

Normal Owner module blocks are no longer retained or uploaded as application defects.

### Migration completion

- Introduces an authoritative registry with `implemented`, `partial` and `planned` availability.
- Promotes existing runnable desktop systems—including server scheduling, player moderation, Pterodactyl control, Discord status panels, role systems, organization, embeds, observability and audit logging—to live/implemented status.
- Keeps conceptual website features honest: planned modules cannot become effectively active until their desktop service and interface exist.
- Keeps the Mobile Companion gateway partial and network-disabled until its HTTPS transport is implemented and validated.

### Discord runtime repair

- Restores the complete supervised Discord entry chain. The v0.18.22 audit wrapper had bypassed the role-menu and status-panel runtime installers.
- Applies live module/configuration changes to the running bot.
- Re-registers slash commands after module changes so disabled operations disappear from Discord.
- Prevents old published buttons from operating while their owning module is disabled.
