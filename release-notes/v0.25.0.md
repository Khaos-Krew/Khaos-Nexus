# Khaos Nexus v0.25.0

This stable release advances the Windows desktop application from v0.22.1 to the current integrated production candidate.

## Included

- Installer-first diagnostics and the standalone Khaos Nexus Diagnostics launcher.
- Startup recovery, watchdog, retained logs, redacted support bundles, and shutdown-recovery improvements.
- Satisfactory dedicated-server API support.
- D&D campaign integration for registered Discord bots, including channel/thread/forum bindings, campaign commands, dice privacy, initiative, sessions, attendance, panels, and hardened Supabase authorization.
- Existing Discord automation, game-server operations, scheduling, monitoring, backups, protected credentials, and local-first workflows.

## Android production hold

Android Companion and Mobile Gateway are paused and excluded by Owner directive under ADR-008.

- No Mobile Gateway listener, pairing endpoint, background timer, IPC registration, QR flow, six-digit pairing flow, certificate-fingerprint setup, or mobile navigation is activated in this release.
- Saved Mobile Gateway enablement from an older installation remains ineffective.
- No APK or Android setup link is included or published.
- Existing Android and Mobile Gateway source, branches, tests, signing references, and security evidence remain preserved for a future explicitly authorized resumption.

## Update safety

The existing in-app updater performs the mandatory verified pre-update backup before installation. Stable rollback evidence for v0.22.1 remains preserved.
