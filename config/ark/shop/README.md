# Khaos Nexus ARK Shop launch policy

- Shiny dino-cache outcomes are disabled for launch.
- Normal/X/S cache policy remains, but unsupported variant classes continue to fail back to Normal rather than inventing paths.
- Dino delivery uses Dino Depot `SpawnDinoInBall` and remains fail-closed.
- Shiny can only be re-enabled after a targeted, verified adapter can modify the specific generated Dino Ball without spawning a separate wild Shiny creature.
