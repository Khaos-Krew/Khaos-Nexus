# v0.18.15 interface watchdog

The main preload acknowledged `startup-health:renderer-ready` immediately. Electron can execute preload against the BrowserWindow's initial `about:blank` document before `renderer/index.html` loads, allowing the startup splash to release while the actual interface is absent. Blank/unusable renderer documents were not forwarded to Application Monitor because no renderer IPC error or process crash was required.

v0.18.15 delays readiness until DOMContentLoaded and verifies the real Khaos Nexus application shell. A main-process watchdog independently checks the page, retains diagnostics, queues Application Monitor capture, and displays a local recovery screen instead of an empty black window.
