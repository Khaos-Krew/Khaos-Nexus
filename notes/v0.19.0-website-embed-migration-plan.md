# v0.19.0 website embed migration

Goal: move all existing website-created Discord embeds into the local desktop application so the hosted website can be retired without rebuilding messages by hand.

Requirements:

- Import individual raw Discord JSON payloads, standalone Embed Studio documents, arrays, and bulk website/Supabase export bundles.
- Preserve multiple embeds, authors, URLs, thumbnails, images, footers, timestamps, webhook username/avatar metadata, all action rows, link and interactive buttons, custom IDs, disabled states, and emoji.
- Keep legacy desktop templates and status panels compatible.
- Provide a simple first-embed editor plus an advanced full-payload JSON editor.
- Detect duplicates using stable payload fingerprints.
- Create and verify a local backup before import.
- Produce an import report showing imported, updated, duplicate, skipped, and warning counts.
- Export the complete desktop library as a portable migration bundle.
- Never import or export Discord tokens, RCON credentials, Supabase keys, or other protected values.
