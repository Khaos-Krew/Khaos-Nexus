# v0.18.10 portable diagnostics

The electron-builder portable target previously meant only “no installation.” It continued using the canonical `%APPDATA%\khaos-nexus` profile and created no visible sidecar folder beside the executable. That made installer isolation useful, but made early-startup owner testing difficult because failures before `AppLogger` initialization left no obvious local log.

v0.18.10 preserves the canonical AppData profile so existing configuration, servers, and protected values continue loading. In portable runtime only, it immediately creates `Khaos-Nexus-Portable-Data` beside the executable, with `logs`, `diagnostics`, and `PORTABLE-README.txt`. Bootstrap, Electron process, preload, renderer-process, child-process, startup-release, and manager logs are mirrored there from the earliest possible entry point.
