# v0.18.11 scroll layout correction

v0.18.10 completed startup successfully, exposing a main-layout issue that earlier startup failures had hidden. The document body is intentionally non-scrolling, but the grid children did not both establish independent scroll containers. `.content` used `overflow: auto` without explicit grid-item `min-height: 0`, `.sidebar` had no vertical overflow, and rich-brand CSS forced the sidebar to `overflow: hidden`.

v0.18.11 loads a final scroll-layout stylesheet after all brand layers and explicitly gives the sidebar and content pane independent vertical scrolling in both software and rich-renderer modes.
