# v0.18.9 preload root cause

The working v0.17.2 `main/preload.cjs` required only `electron`. The v0.18 startup path added a relative CommonJS import before bridge exposure. The main BrowserWindow uses `sandbox: true`, so Electron's sandboxed preload `require` polyfill cannot load local CommonJS modules. The preload therefore aborts before exposing `window.khaos` and before invoking `startup-health:renderer-ready`, leaving startup at 68% with profile/configuration checks complete but the protected renderer bridge pending.
