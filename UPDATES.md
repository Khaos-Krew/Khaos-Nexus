# Khaos Nexus in-app updates

Khaos Nexus provides a stable GitHub Releases update channel inside the Windows desktop application.

## Installed build

The NSIS installer uses `electron-updater` and the release metadata generated by `electron-builder`.

1. Open **Settings** → **In-App Update Center**.
2. Select **Check Now**.
3. When a release is available, select **Download Update**.
4. After verification, select **Install & Restart**.

A verified Khaos Nexus configuration backup is created before installation.

## Portable build

The portable executable is also supported:

1. The app requests the latest public release from `Khaos-Krew/Khaos-Nexus`.
2. It selects the matching `Khaos-Nexus-Portable-<version>-x64.exe` asset.
3. It downloads the file into the local update staging folder.
4. It verifies the SHA-256 digest supplied by GitHub.
5. A detached PowerShell helper waits for Khaos Nexus to close, replaces the original portable executable, and starts the new version.

Portable self-replacement requires write access to the folder containing the running portable executable.

## Stable release pipeline

Validated versions are published through `.github/workflows/stable-release.yml`.

1. The application version is set in `package.json`.
2. The development branch must pass CI and Windows packaging.
3. A branch named exactly `release/v<package version>` is created from the validated commit.
4. The stable release workflow verifies that the branch and package versions match.
5. It reruns the complete tests and syntax checks.
6. It rebuilds the Windows installer and portable executable.
7. It verifies all updater assets exist and generates a SHA-256 checksum manifest.
8. It publishes a non-draft, non-prerelease GitHub Release and marks it as latest.

This prevents temporary workflow artifacts from being mistaken for update releases and keeps the in-app button tied only to validated stable builds.

## Release assets

A live update includes:

- `Khaos-Nexus-Setup-<version>-x64.exe`
- `Khaos-Nexus-Setup-<version>-x64.exe.blockmap`
- `Khaos-Nexus-Portable-<version>-x64.exe`
- `latest.yml`
- `release-checksums.txt`

The Windows package icon is generated from the supplied 256×256 Khaos Nexus crest source.

## Safety

- Drafts and prereleases are ignored by the application.
- Downgrades are not installed.
- Portable downloads are checked against GitHub's SHA-256 release-asset digest.
- A pre-update backup is created before installation.
- The application accepts releases only from the official `Khaos-Krew/Khaos-Nexus` repository.
