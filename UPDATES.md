# Khaos Nexus in-app updates

Khaos Nexus 0.8.0 adds a stable GitHub Releases update channel inside the desktop application.

## Installed build

The NSIS installer uses `electron-updater` and the release metadata generated by `electron-builder`.

1. Open **Settings** → **In-App Update Center**.
2. Select **Check Now**.
3. When a release is available, select **Download Update**.
4. After verification, select **Install & Restart**.

A verified Khaos Nexus configuration backup is created before installation.

## Portable build

The portable executable is also supported:

1. The app requests the latest public release from `Khaos-Krew/Khaos-Nexus`.
2. It selects the matching `Khaos-Nexus-Portable-<version>-x64.exe` asset.
3. It downloads the file into the local update staging folder.
4. It verifies the SHA-256 digest supplied by GitHub.
5. A detached PowerShell helper waits for Khaos Nexus to close, replaces the original portable executable, and starts the new version.

Portable self-replacement requires write access to the folder containing the running portable executable.

## Release requirements

A live update must be a published, non-draft, non-prerelease GitHub Release containing:

- `Khaos-Nexus-Setup-<version>-x64.exe`
- `Khaos-Nexus-Portable-<version>-x64.exe`
- `latest.yml`
- the NSIS blockmap generated by `electron-builder`

The repository's tagged Windows workflow builds and publishes those files.
